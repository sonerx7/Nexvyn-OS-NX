# Yayımlama

[English](README.md) · **Türkçe**

Bir uygulama, oyun, tema ya da yazı tipi Nexvyn OS Uygulama Mağazası'na şöyle girer: bu depoya açılan ve bakımcının
inceleyip onayladığı bir pull request.

| Belge | Kimin için |
|---|---|
| [PUBLISHING.tr.md](PUBLISHING.tr.md) | Geliştiriciler: akış (fork → `Store/...` → denetimler → pull request → inceleme → merge), klasör düzeni, `app.json`, izinler, `store.json`, ekran görüntüleri, içerik kuralları, güncellemeler, bildirim ve kaldırma, imzalama |
| [REVIEW.tr.md](REVIEW.tr.md) | Bakımcının onay için kullandığı liste; pull request açmadan önce siz de geçin |
| [Pull request şablonu](../../.github/PULL_REQUEST_TEMPLATE.md) | Pull request açınca kendiliğinden doldurulur |
| [Uygulama bildir](https://github.com/sonerx7/Nexvyn-OS-NX/issues/new?template=report-app.yml) | Kullanıcılar: mağazadaki bir şey kurallara uymuyor |
| [Sorular](https://github.com/sonerx7/Nexvyn-OS-NX/issues/new?template=submission-question.yml) | Geliştiriciler: göndermeden önce ya da gönderirken sorun |
