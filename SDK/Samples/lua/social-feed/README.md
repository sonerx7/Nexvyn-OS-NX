# Social Feed

**English** · [Türkçe](README.tr.md)

A photo feed, a photo grid and a vertical clip pager: the building blocks of feed, photo and short-video apps on the
SDK 1.9 functions. About 250 lines of commented Lua.

| | |
|---|---|
| Id | `com.sonerx7.demo.socialfeed` |
| Language | Lua 5.4 |
| Min SDK | 1.9 |
| Permissions | `network` |
| Gamepad | cursor |
| Window | 720 × 640, resizable |

## What it teaches

- `net.request` with `responseType = "json"`, `cache` (offline answer, marked `stale`) and `retry`; the bundled
  `media/feed.json` when the web copy cannot be reached
- `gfx.imageUrl(url, maxSize)`: photos from the web with the disk and memory cache, thumbnails for the grid, a
  placeholder while they load
- `ui.beginFeed` / `ui.feedItem` / `ui.endFeed`: a virtualized list with measured post heights, a 3–4 column grid,
  pull-to-refresh and infinite scroll
- `ui.pager` with `media.open` / `media.draw` / `media.set`: one clip per page, only the current and the next player
  open, mute, a spinner while buffering, pause in `app.suspend`
- `ui.richText` captions (`**bold**`, links, `@mentions`, `#hashtags`), `ui.measureRichText`, `sys.relativeTime`
- `sys.share` with a `sys.appUrl` link back to a post (`app.open("post:12")`)

**Controls:** touch or the cursor; pull the feed down to refresh, swipe the clips up and down (D-pad up / down too).

## Running it

- **On the console:** copy the `source/` folder to `sdmc:/NexvynOS/Applications/` as `socialfeed.nxvapp` (or
  `python SDK/Tools/nxv/nxv.py push SDK/Samples/lua/social-feed/source --host <console-ip>`) and open it from Launcher.
- **Check on the PC:** `python tools/lua_check.py SDK/Samples/lua/social-feed/source` (the SDK mocks).

## Media

The 12 photos, 3 clips and the icon are generated by `make_social_media.py` (procedural art and tones). They are
dedicated to the public domain: **CC0 1.0**. The app reads them from this repository on the web
(`raw.githubusercontent.com`, so the image cache has something to cache) and from its own `media/` folder when offline.
