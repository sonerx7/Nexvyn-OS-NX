# NetX-Browser Mini

A lightweight Nexvyn OS browser with up to eight tabs, an editable address bar, bookmarks, history and two toolbar themes. Choose a search engine in Settings. DuckDuckGo HTML results have a native results view.

Search YouTube and play compatible public videos in the same NetX tab. The player has pause, seek, mute, playback speed and a window-filling view. Netflix title pages can show and play trailers published by Netflix. Netflix sign-in, DRM-protected movie or episode playback, YouTube account features and general website JavaScript are unavailable.

| Field | Value |
| --- | --- |
| App ID | `com.sonerx7.nxbrowser` |
| Runtime | JavaScript |
| SDK | 1.9 minimum, 1.13 target |
| Network permission | Fetch pages, results, pictures and media |
| Launch permission | Open the WebGL Cubemap demo in the Nexvyn system browser |

Select the address bar to type with the Nexvyn OS keyboard. The chevron on the tab strip lists all tabs, including tabs outside the visible strip. Menu settings control language, appearance, history and whether tabs reopen on the next launch.
