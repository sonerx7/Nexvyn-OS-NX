## Features
- **7 Workspaces:** Layout, Modeling, Sculpting, UV Edit, Shading, Animation, GeoNodes.
- **OpenGL 4.3 Viewport:** Studio Lighting, Red Wax MatCap shader, Wireframe, Material Preview (Principled BSDF v2), Rendered (EEVEE Next).
- **3D Sculpting:** Draw, Clay, Smooth, Flatten, Inflate, Grab brushes with X-Axis symmetry.
- **Modifiers & Geometry Nodes:** Subdivision Surface, Mirror, Solidify, and visual Geometry Node graphs.
- **Animation:** Dope Sheet keyframe timeline with live playback.
- **Export:** `.blend`, `.obj`, `.gltf`, `.stl`.

## Controls
- **L-Stick / Drag:** Orbit 3D Viewport
- **R-Stick / Right-Drag:** Pan Camera
- **ZL / ZR / Wheel:** Zoom In / Out
- **L / R:** Switch Workspaces
- **D-Pad:** Top / Front / Side / Reset View
- **- (Minus) / Tab:** Toggle Object / Edit / Sculpt Mode
- **+ (Plus) / Space:** Play / Pause Animation
- **X:** Delete Selected Object
