# Metronom / Metronome

Tempo tıklama, ölçü seçenekleri ve sallanan sarkaçlı metronom

Metronome with tap tempo, time signatures and a swinging pendulum

Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Medya** bölümünden yüklenir. Kimliği (`metronome`) aynı kaldığı için eski veriler korunur.
