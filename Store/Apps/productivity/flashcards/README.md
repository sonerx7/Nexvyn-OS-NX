# Kelime Kartları / Flashcards

Kelime kartları ve aralıklı tekrar ile öğrenin

Learn with flashcards and spaced repetition

Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Verimlilik** bölümünden yüklenir. Kimliği (`flashcards`) aynı kaldığı için eski veriler korunur.

## Yenilikler 1.1 / What's new in 1.1

**Türkçe:** Aralıklı tekrar, testler, içe aktarma.

- Beş kutulu aralıklı tekrar ya da tüm kartlarla alıştırma
- Çoktan seçmeli Test modu (1–4 tuşları)
- Desteleri CSV / TSV / TXT olarak içe ve dışa aktarma
- Ön → arka, arka → ön ya da karışık sorma
- Çalışma serisi, deste istatistikleri ve Hızlı Arama
- Hazır İngilizce–Türkçe başlangıç destesi

**English:** Spaced repetition, quizzes and imports.

- Spaced repetition with five boxes, or practise all cards
- Multiple-choice Quiz mode (keys 1–4)
- Import and export decks as CSV / TSV / TXT
- Ask front → back, back → front or mixed
- Study streak, per-deck stats and Quick Search
- A ready-made English–Turkish starter deck
