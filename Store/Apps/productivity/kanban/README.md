# Görev Panosu / Kanban





Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Verimlilik** bölümünden yüklenir. Kimliği (`kanban`) aynı kaldığı için eski veriler korunur.

## Yenilikler 1.1 / What's new in 1.1

**Türkçe:** Panolar, kontrol listeleri, sürükle-bırak.

- Düzenlenebilir sütunlu birden çok pano
- Açıklama, son tarih, altı renk etiketi ve kontrol listesi olan kartlar
- Pano filtresi ve Hızlı Arama sonuçları
- Sürükle-bırak ya da tam klavye ve kumanda denetimi
- Markdown dışa aktarma, JSON yedekleme ve geri yükleme
- Açık ve koyu mod

**English:** Boards, checklists and drag-and-drop.

- Multiple boards with editable columns
- Cards with description, due date, six colour labels and a checklist
- Board filter and Quick Search results
- Drag and drop, or full keyboard and controller control
- Markdown export, JSON backup and restore
- Light and dark mode
