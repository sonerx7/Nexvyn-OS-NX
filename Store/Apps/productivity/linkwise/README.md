# Linkwise

Linked notes, backlinks and a graph. Bağlantılı notlar, geri bağlantılar ve grafik.

Linkwise is a Markdown knowledge base. Put a title in double square brackets to link two notes; every note lists the notes that link to it, and a live graph shows how your ideas connect.

• Headings, lists, tasks, quotes, code and tags rendered as you write
• Backlinks, unlinked mentions and an outline beside each note
• Force-directed graph of all notes or just the neighbourhood
• Full-text search, tag filters, pinned notes and daily notes
• Undo/redo, Markdown import/export, JSON backup, Quick Search

## Türkçe

Linkwise bir Markdown bilgi bankasıdır. İki notu bağlamak için bir başlığı çift köşeli parantez içine yaz; her not ona bağlanan notları listeler, canlı bir grafik de fikirlerinin nasıl bağlandığını gösterir.

• Başlıklar, listeler, görevler, alıntılar, kod ve etiketler yazarken biçimlenir
• Her notun yanında geri bağlantılar, bağlantısız anılmalar ve ana hat
• Tüm notların ya da yalnızca çevrenin kuvvet yönlü grafiği
• Tam metin arama, etiket süzgeçleri, sabitlenen notlar ve günlük notlar
• Geri al/yinele, Markdown içe/dışa aktarma, JSON yedek, Hızlı Arama
