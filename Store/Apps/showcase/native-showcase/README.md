# Native SDK Showcase

Native SDK için teknik demo: Nexvyn OS penceresinde çalışan gerçek C ve C++ kodu.
A tech demo of the Native SDK: real C and C++ code running in a Nexvyn OS window.

## Özellikler / Features

- OpenGL ile çizilen dönen 3B küp ve canlı kare hızı. / A rotating 3D cube drawn with OpenGL, with a live frame rate.
- Kumanda, analog çubuk ve dokunma girdisi, ses, dosyalar, thread'ler, sistem servisleri. / Controller, stick and touch input, audio, files, threads, system services.
- zstd, lz4, SQLite ve paylaşımlı kütüphane denemeleri. / zstd, lz4, SQLite and shared library round trips.
- Durum sayfası her özelliği sınar ve sonucu listeler. / A Status page tests every feature and lists the result.
- Sayfalar L ve R ile ya da dokunarak değişir. / Pages switch with L and R, or by touch.

## Kurulum / Install

- **Mağaza / Store:** App Market > Developer > Native SDK Showcase > Get.

İzinler / Permissions: `files`, `network`, `notifications` (yalnızca kendi self-test'leri için / only for its own self-tests).
`Crash` sayfası bilerek çökme dener; her denemeden önce onay ister. / The `Crash` page crashes the app on purpose and asks first.

Gerekenler / Needs: Nexvyn OS 1.2.2 or newer (Native SDK 1.1, `minSdk` 1.10).
