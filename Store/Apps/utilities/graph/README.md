# Grafik Çizici / Graph Plotter

Fonksiyon grafikleri çizin, eğrileri izleyin, kökleri bulun

Plot functions, trace curves and find roots

Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Araçlar** bölümünden yüklenir. Kimliği (`graph`) aynı kaldığı için eski veriler korunur.
