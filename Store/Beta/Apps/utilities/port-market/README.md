# Port Market

Port Market is a Nexvyn OS utility for a private SD-card library and live tracking of selected Internet Archive items.

Add an Internet Archive item ID or details URL. Port Market checks for new `.nxvapp` files and can download a selected package with progress and a size check. Open the downloaded package in the system installer to review it. The Local tab can also read the studio's SD-card catalog.

| ID | Version | Runtime | SDK | Permissions |
| --- | --- | --- | --- | --- |
| `com.sonerx7.portmarket` | 0.2.1 beta | Nexvyn OS JavaScript | 1.15 | Network, user-selected folder |

Navigate with touch, pointer or gamepad. See [known issues](KNOWN_ISSUES.md).
