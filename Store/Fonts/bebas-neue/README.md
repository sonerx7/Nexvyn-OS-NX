# Bebas Neue

**Tall, bold capitals for titles**

Bebas Neue is an all-caps display font: tall, condensed and bold. Use it big, for slide titles, posters, game menus and score boards; it is not meant for body text.

- Styles: Regular
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `bebas-neue.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Başlıklar için uzun, kalın büyük harfler**

Bebas Neue yalnızca büyük harfli bir başlık yazı tipidir: uzun, dar ve kalın. Büyük boyutta kullanın: sunum başlıkları, afişler, oyun menüleri ve skor tabloları; gövde metni için değildir.
