# Caveat

**Lively handwriting for notes**

Caveat looks like quick, natural handwriting with a marker. Great for sticky notes, cards, drawings in Paint and informal slides.

- Styles: Regular, Bold
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `caveat.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Notlar için canlı bir el yazısı**

Caveat, keçeli kalemle hızlıca yazılmış doğal bir el yazısı gibi görünür. Yapışkan notlar, kartlar, Çizim'deki resimler ve gündelik sunumlar için harika.
