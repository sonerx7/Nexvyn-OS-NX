# Fira Code

**A monospaced font for code**

Fira Code is a monospaced font with clear, distinct letters (0 and O, 1, l and I never look alike) for the Text Editor, Studio and the Console. Every character has the same width, so columns line up.

- Styles: Regular, Bold
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `fira-code.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Kod için eş aralıklı bir yazı tipi**

Fira Code, Metin Düzenleyici, Studio ve Konsol için net ve birbirinden kolay ayrılan harfleri olan (0 ile O, 1, l ve I asla karışmaz) eş aralıklı bir yazı tipidir. Her karakter aynı genişlikte olduğundan sütunlar hizalı durur.
