# Lora

**A contemporary serif with calligraphic roots**

Lora mixes brushed curves with sharp serifs. It has a literary feel that suits stories, letters, journals and elegant slides, and reads well in long paragraphs.

- Styles: Regular, Bold, Italic
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `lora.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Kaligrafi kökenli çağdaş bir serif**

Lora fırçayla çizilmiş kıvrımları keskin seriflerle birleştirir. Hikâyelere, mektuplara, günlüklere ve şık sunumlara yakışan edebi bir havası vardır; uzun paragraflarda da rahat okunur.
