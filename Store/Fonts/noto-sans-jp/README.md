# Noto Sans JP

**Japanese font pack (CJK)**

Noto Sans JP is a Japanese font from the Noto family. Install it on a console that does not have the system's shared fonts (for example in an emulator without firmware fonts): Nexvyn OS then draws Japanese text with it everywhere, from the menus to web pages. It also appears in the Fonts app and in the font menus of the apps.

- Styles: Regular
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `noto-sans-jp.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Japonca yazı tipi paketi (CJK)**

Noto Sans JP, Noto ailesinden bir Japonca yazı tipidir. Sistemin paylaşılan yazı tipleri olmayan bir konsola (örneğin donanım yazılımı yazı tipleri olmayan bir emülatöre) kurun: Nexvyn OS Japonca metinleri menülerden web sayfalarına kadar her yerde bununla çizer. Yazı Tipleri uygulamasında ve uygulamaların yazı tipi menülerinde de görünür.
