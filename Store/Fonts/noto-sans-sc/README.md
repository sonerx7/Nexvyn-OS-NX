# Noto Sans SC

**Simplified Chinese font pack (CJK)**

Noto Sans SC is a Simplified Chinese font from the Noto family. Install it on a console that does not have the system's shared fonts (for example in an emulator without firmware fonts): Nexvyn OS then draws Simplified Chinese text with it everywhere, from the menus to web pages. It also appears in the Fonts app and in the font menus of the apps.

- Styles: Regular
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `noto-sans-sc.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Basitleştirilmiş Çince yazı tipi paketi (CJK)**

Noto Sans SC, Noto ailesinden bir Basitleştirilmiş Çince yazı tipidir. Sistemin paylaşılan yazı tipleri olmayan bir konsola (örneğin donanım yazılımı yazı tipleri olmayan bir emülatöre) kurun: Nexvyn OS Basitleştirilmiş Çince metinleri menülerden web sayfalarına kadar her yerde bununla çizer. Yazı Tipleri uygulamasında ve uygulamaların yazı tipi menülerinde de görünür.
