# Source Serif 4

**A classic text serif for documents**

Source Serif is a text face in the tradition of the transitional serifs, tuned for both print and screen. It is a calm, neutral companion for reports, letters and the Writer.

- Styles: Regular, Bold, Italic
- License: SIL Open Font License 1.1 (see [LICENSE](LICENSE))
- Source: [google/fonts](https://github.com/google/fonts)
- Package: `source-serif.nxvfont` (install it from the App Market, category Fonts)

## Türkçe

**Belgeler için klasik bir metin serifi**

Source Serif, geçiş dönemi seriflerinin geleneğinden gelen, hem baskı hem ekran için ayarlanmış bir metin yazı tipidir. Raporlar, mektuplar ve Kelime İşlemci için sakin, nötr bir yol arkadaşı.
