# Asteroitler / Asteroids

Küçük bir gemiyle asteroit kuşağında uç: dön, hızlan ve kayaları küçük parçalara ayır, uçan dairelerden kaç, dalgalara dayan.

Pilot a tiny ship through an asteroid field: rotate, thrust and blast the rocks into smaller pieces, dodge flying saucers and survive the waves.

## Kontroller / Controls

- **D-pad / Sol çubuk ←→ / Ok tuşları**: Dön / Rotate
- **D-pad ↑ / B / W**: İtki / Thrust
- **A / Boşluk / Space**: Ateş / Fire (basılı tut / hold)
- **X / Y / C tuşu**: Hiperuzay / Hyperspace
- **Dokunmatik / Touch**: Basılı tut: gemi parmağa döner, ateş eder ve ilerler / Hold: the ship turns, fires and flies to your finger
- **+ / P / Esc**: Duraklat / Pause
