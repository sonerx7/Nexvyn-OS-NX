# Yolu Geç / Road Crosser

Kalabalık yolu ve hızlı nehri zıplayarak geç: arabalardan kaç, kütüklere ve dalan kaplumbağalara bin, süre bitmeden beş nilüfer yuvasını doldur.

Hop across a busy road and a fast river: dodge the traffic, ride logs and diving turtles and fill all five lily-pad homes before time runs out.

## Kontroller / Controls

- **D-pad / Sol çubuk / Ok tuşları / WASD**: Zıpla / Hop (basılı tut / hold)
- **Dokunmatik / Touch**: Kaydır ya da kurbağanın yanına dokun / Swipe or tap beside the frog
- **+ / P / Esc**: Duraklat / Pause

## Kurulum

Uygulama Mağazası > Oyunlar
