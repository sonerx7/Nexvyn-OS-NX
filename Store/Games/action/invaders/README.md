# Uzay İstilası / Space Invaders

Yürüyen uzaylı sıralarına karşı hattı koru. Kalkanların arkasına saklan, gizemli daireyi vur ve dalga dalga gelen istilaya dayan.

Hold the line against rows of marching invaders. Hide behind the shields, shoot down the mystery saucer and survive wave after wave.

## Kontroller / Controls

- **D-pad / Sol çubuk / Ok tuşları**: Topu sağa sola sür / Move the cannon
- **A / B / Boşluk / Space**: Ateş / Fire (basılı tut / hold)
- **Dokunmatik / Touch**: Parmağını sürükle, otomatik ateş eder / Drag; fires automatically
- **+ / P / Esc**: Duraklat / Pause

## Kurulum

Uygulama Mağazası > Oyunlar
