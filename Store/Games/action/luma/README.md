# Luma: Starfall Islands / Luma: Yıldız Adaları

A 3D exploration platform adventure with ten worlds, broad districts, walkable roads and alternative routes. Discover stars, rescue a friend, clear arenas and activate seals. Eight enemy behaviours, real UV textures, 48 original models, ten original music loops, checkpoints and a minimap. English/Turkish game text. Supplied images are labelled software previews; real-device validation is pending.

On dünya, geniş bölgeler, yürünebilir yollar ve alternatif rotalarla 3B keşif-platform macerası. Yıldızları bul, dostunu kurtar, arenaları temizle ve mühürleri aç. Sekiz düşman davranışı, gerçek UV dokuları, 48 özgün model, on özgün müzik, kayıt ve mini harita. Görseller etiketli yazılım önizlemeleridir; cihaz doğrulaması bekleniyor.

## Controls / Kontroller

WASD/arrows: move; Space/A: jump; X/B: dash; C/Y: slam; Esc/Plus: pause. / WASD/oklar: hareket; Space/A: zıpla; X/B: atıl; C/Y: yere sert in; Esc/Artı: duraklat.

Touch controls and a full help screen are included. Open the `.nxvapp` package in Nexvyn OS Files to install. / Dokunmatik kontroller ve tam yardım ekranı vardır. Kurmak için `.nxvapp` paketini Nexvyn OS Dosyalar uygulamasından aç.

## Assets / Varlıklar

48 original models, 30,330 source triangles, six UV texture maps and ten original music loops. The promotional icon was generated for this game with OpenAI ImageGen. / 48 özgün model, 30.330 kaynak üçgen, altı UV doku haritası ve on özgün müzik döngüsü. Tanıtım ikonu bu oyun için OpenAI ImageGen ile üretildi.

Code, models, textures and music were authored for this game. No external franchise characters, downloaded music, bundled fonts, tracking, advertising or embedded credentials. / Kod, modeller, dokular ve müzik bu oyun için üretildi. Haricî marka karakteri, indirilmiş müzik, paketlenmiş font, izleme, reklam veya gömülü kimlik bilgisi yoktur.

## Validation / Denetim

The Lua 5.4 behavioral suite passed: 1,092 road-geometry transitions, 90 links walked both ways with the real controller, eight enemy behaviours, quests, physics, saves and ten scene/lifecycle flows. / 1.092 yol geometrisi geçişi, gerçek kontrolcüyle iki yönde yürütülen 90 bağlantı, sekiz düşman davranışı, görevler, fizik, kayıt ve on sahnenin yaşam döngüsü.

Strict local SDK-adapter checks cover menus, keyboard/controller/touch, minimum/default window sizes, saves and suspend/resume. `nxv check`, package CRC, SHA-256 manifests and exact package/source matching pass. Real console performance and the full OS runtime checker remain unverified. / Sıkı yerel SDK adaptörü menüleri, klavye/kumanda/dokunmatiği, en küçük/varsayılan pencere boyutlarını, kayıt ve askıya alma/devam akışlarını denetledi. `nxv check`, paket CRC, SHA-256 manifest ve birebir paket/kaynak denetimleri geçti. Gerçek konsol performansı ve tam OS çalışma zamanı denetleyicisi henüz doğrulanmadı.

`screenshots/` contains labelled software previews of actual Lua scene/UI commands, not device captures. / Görseller gerçek Lua sahne/arayüz komutlarının etiketli yazılım önizlemeleridir; cihaz görüntüsü değildir.
