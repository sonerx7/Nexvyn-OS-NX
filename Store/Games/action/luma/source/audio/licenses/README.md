# Audio sources / Ses kaynakları

New compositions, note arrangements, mixing and sound design were created for these games. Scores were rendered offline with GeneralUser GS by S. Christian Collins (License v2.0); only finished recordings are distributed, not the SoundFont. Foley variations and layered effects use Kenney Impact Sounds (CC0-1.0). The instrument/sfx licenses are in this directory. The game's GPL licence does not replace these source licences.
