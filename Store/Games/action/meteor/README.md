# Meteor Yağmuru / Meteor Shower

Gittikçe hızlanan meteor yağmurundan kaç. Yıldız topla, kıl payı kaçışlarla puan al; kalkan, ağır çekim ve mıknatısları kap.

Dodge a storm of falling meteors that keeps getting faster. Collect stars, score near misses and grab shields, slow motion and magnets.

## Kontroller / Controls

- **Sol çubuk / D-pad / Ok tuşları / WASD**: Gemiyi uçur / Fly the ship
- **Dokunmatik / Fare**: Ekranda sürükle, gemi parmağını izler / Drag anywhere; the ship follows
- **+ / P / Esc**: Duraklat / Pause
