# Uzay Arenası / Orbit Arena

Yukarıdan bakışlı arena nişancı: dalgalara dayan, rekorunu kır

Top-down arena shooter: survive the waves and beat your high score

Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Oyunlar** bölümünden yüklenir. Kimliği (`spacearena`) aynı kaldığı için eski veriler korunur.
