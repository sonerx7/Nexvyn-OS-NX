# Station Zero

A third-person stealth and escape game for Nexvyn OS. Kepler station has gone dark: sneak past the security drones,
restore the reactor, crack the bridge lockdown and reach the escape pod before the bay vents.

- Four sectors: cargo hangar, reactor and labs, command bridge, escape bay
- Terminal puzzles (reactor feed routing, a four-digit lockdown code hidden in the crew logs), keycard, lever and
  pressure-plate doors, checkpoints and automatic saving
- Drones that patrol, notice you, raise the alarm and hunt you; sentries that open fire
- Physically based rendering with real-time lights, a shadow-casting searchlight, bloom, sparks and steam
- Controller, keyboard or touch; handheld and docked

## Controls

| Action | Controller | Keyboard |
|---|---|---|
| Move | left stick (push lightly to walk quietly) | W A S D |
| Camera | right stick | J / L |
| Use | A | E or Enter |
| Sprint (drones hear it) | ZR | Shift |
| Sneak | ZL | C |
| Pause | + | Esc |

## Made with

Nexvyn OS SDK 1.9 (Lua, the pbr renderer) and Game Engine 2 parts: Logic 2.0 behaviours (guard_alert, aim_fire,
guard_alarm, door_key, lever, pressure_plate, checkpoint_save), the base hero and its locomotion machine, camera rails,
Sound 2.0 recipes and music stems, and the level generator for the escape bay's maintenance ducts.

Station architecture, props, the security robot, the maintenance drone and the escape pod come from the author's own 3D
kits, reduced for the console. Everything else (hero, sound, music, the view of space) is generated by the project's
own scripts.
