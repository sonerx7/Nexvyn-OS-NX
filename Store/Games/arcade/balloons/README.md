# Balon Patlat / Balloon Pop

Yükselen balonları uçup gitmeden patlat. Ardışık patlatmalarla kombo yap; altın, buz, kalp ve patlama balonlarını yakala, bombalardan uzak dur.

Pop the rising balloons before they float away. Chain pops for combos, grab golden, ice, heart and blast balloons, and stay away from bombs.

## Kontroller / Controls

- **Dokunmatik / Fare**: Balona dokun ya da tıkla / Tap or click a balloon
- **Sol çubuk / D-pad / Ok tuşları**: Nişangâhı oynat / Move the crosshair
- **A / B / Boşluk / Space**: Patlat / Pop
- **+ / P / Esc**: Duraklat / Pause

## Kurulum

Uygulama Mağazası > Oyunlar
