# Labirent Yiyici / Maze Eater

Üç hayalet peşindeyken labirentteki bütün noktaları ye. Güç hapını kap ve avcıyı av yap.

Gobble every dot in the maze while three ghosts hunt you down. Grab a power pellet and turn the tables.

## Kontroller / Controls

- **D-pad / Sol çubuk / Ok tuşları / WASD**: Yön / Direction
- **Dokunmatik / Touch**: Kaydır ya da gitmek istediğin yöne dokun / Swipe or tap towards where you want to go
- **+ / P / Esc**: Duraklat / Pause

## Kurulum

Uygulama Mağazası > Oyunlar
