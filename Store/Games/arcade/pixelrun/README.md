# Pixel Koşu / Pixel Run

Piksel sanatlı platform oyunu: üç bölümde koş, zıpla, düşmanları ez, altın topla

A pixel-art platformer: run, jump, stomp and collect coins across three levels

Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Oyunlar** bölümünden yüklenir. Kimliği (`pixelrun`) aynı kaldığı için eski veriler korunur.
