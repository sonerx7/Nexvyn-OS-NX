# Pong / Pong

Masa tenisi klasiği: üç zorluk seviyesinde bilgisayara karşı 7 sayıya ilk ulaşan kazanır ya da aynı konsolda iki kişi oynayın.

The table-tennis classic: first to 7 against the CPU on three difficulty levels, or two players on one console.

## Kontroller / Controls

- **1. oyuncu / Player 1**: D-pad ↑↓, sol çubuk, W / S
- **2. oyuncu / Player 2**: X / B, sağ çubuk, ↑ / ↓ ok tuşları
- **Dokunmatik / Touch**: Raketi parmağınla sürükle (2 kişide ekranın kendi yarın) / Drag your paddle (your half in 2-player)
- **Başlık ekranı / Title**: ←→ zorluk, ↑↓ mod / difficulty and mode
- **+ / P / Esc**: Duraklat / Pause
