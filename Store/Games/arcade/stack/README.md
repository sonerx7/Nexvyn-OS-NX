# Kule Kur / Tower Stack

Kayan blokları doğru anda bırakıp en yüksek kuleyi kur. Taşan kısımlar kesilir; kusursuz bırakışlar seri yapar ve bloğunu yeniden büyütür.

Drop the sliding blocks at the right moment to build the tallest tower. Overhangs are cut off; perfect drops build streaks that grow your block back.

## Kontroller / Controls

- **A / B / D-pad ↑↓ / Boşluk / Space**: Bloğu bırak / Drop the block
- **Dokunmatik / Fare**: Ekrana dokun / Tap or click anywhere
- **+ / P / Esc**: Duraklat / Pause

## Kurulum

Uygulama Mağazası > Oyunlar
