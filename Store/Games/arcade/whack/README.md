# Köstebek Vur / Whack-a-Mole

60 saniyede olabildiğince çok köstebek vur. Ardışık vuruşlarla kombo çarpanı kazan, altın köstebek ve saatleri yakala, bombaya asla vurma.

Whack as many moles as you can in 60 seconds. Chain hits for a combo multiplier, grab golden moles and clocks, and never hit a bomb.

## Kontroller / Controls

- **Dokunmatik / Fare**: Köstebeğe dokun ya da tıkla / Tap or click a mole
- **D-pad / Sol çubuk / Ok tuşları**: Delik seç / Choose a hole; **A / B / Boşluk**: Vur / Whack
- **1–9 tuşları / keys**: Sayısal tuş takımı düzeninde doğrudan vur / Whack directly (numeric keypad layout)
- **+ / P / Esc**: Duraklat / Pause

## Kurulum

Uygulama Mağazası > Oyunlar
