# XOX / Tic-Tac-Toe

Kolay ya da yenilmez (minimax) bilgisayara veya aynı cihazda bir arkadaşınıza karşı klasik XOX; ipucu, geri alma ve kalıcı skor tablosu.
Classic tic-tac-toe against an easy or an unbeatable (minimax) computer or a friend on the same console, with hints, undo and a saved scoreboard.

## Kontroller / Controls

- **Dokunmatik / Touch:** kareye dokunun / tap a square.
- **Kumanda / Controller:** D-pad imleci taşır, A yerleştirir, B geri alır, Y ipucu, X yeni oyun, L/R mod, + duraklat /
  D-pad moves the cursor, A places, B undo, Y hint, X new game, L/R mode, + pause.
- **Klavye / Keyboard:** oklar + Enter veya sayısal tuş takımı düzeninde 1–9, Z geri al, H ipucu, N yeni oyun, Esc duraklat /
  arrows + Enter or 1–9 in numpad layout, Z undo, H hint, N new game, Esc pause.

Kurulum: Uygulama Mağazası > Oyunlar
