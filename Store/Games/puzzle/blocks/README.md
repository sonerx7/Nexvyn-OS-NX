# Blok Düşür / Falling Blocks

Düşen blok bulmacası: parçaları döndür ve bırak, dolu satırları temizle, seviye atla. Saklama, sıradaki parça ve gölge parça desteğiyle.

Falling blocks puzzle: rotate and drop the pieces, clear full lines and climb the levels. With hold, preview and ghost piece.

## Yenilikler 1.1 / What's new in 1.1

**Türkçe:** Maraton, Sprint, Ultra ve Kazı modları.

- Maraton, Sprint (40 satır), Ultra (2 dakika) ve Kazı
- Her birinin kendi rekorları olan Kolay, Normal ve Zor hız
- Her mod için bronz, gümüş, altın madalyalar ve ilk 10 tablosu
- Tutma, gölge parça, üç parçalık önizleme ve duvar itme
- Kumanda, klavye ya da dokunmatik (sürükle, döndürmek için dokun, bırakmak için aşağı kaydır)

**English:** Marathon, Sprint, Ultra and Dig modes.

- Marathon, Sprint (40 lines), Ultra (2 minutes) and Dig
- Easy, Normal and Hard speeds, each with its own records
- Bronze, silver and gold medals and a top-10 table per mode
- Hold, ghost piece, three-piece preview and wall kicks
- Controller, keyboard or touch (drag, tap to rotate, flick down to drop)

## Kontroller / Controls

- **D-pad / Sol çubuk / Ok tuşları**: Sola, sağa, aşağı / Move and soft drop
- **A / ↑ tuşu**: Saat yönünde döndür / Rotate clockwise; **B / X tuşu**: Ters döndür / Rotate counter-clockwise
- **D-pad yukarı / Boşluk**: Anında bırak / Hard drop
- **X / Y / L / R / C tuşu**: Parçayı sakla / Hold
- **Dokunmatik / Touch**: Sürükle, dokun = döndür, aşağı fırlat = bırak / Drag, tap to rotate, flick down to drop
- **+ / P / Esc**: Duraklat / Pause
