# Şifre Kır / Code Breaker

Mastermind: gizli renk şifresini 10 denemede bulun. Siyah pim doğru renk doğru yer, beyaz pim doğru renk yanlış yer demektir. Klasik (4 pim, 6 renk) ve zor (5 pim, 8 renk) mod, tekrar eden renkler açık/kapalı, renk körleri için numaralı pimler, ipucu ve tahmin dağılımlı istatistikler.
Mastermind: find the secret colour code in 10 tries. A black peg means right colour in the right place, a white peg right colour in the wrong place. Classic (4 pegs, 6 colours) and hard (5 pegs, 8 colours), duplicates on/off, numbered pegs for colour-blind players, hints and statistics with a guess distribution.

## Kontroller / Controls

- **Dokunmatik / Touch:** alttaki paletten renge dokunun, yuvayı seçmek için satırdaki yuvaya dokunun, ✓ ile gönderin / tap a colour in the palette, tap a slot to select it, ✓ to submit.
- **Kumanda / Controller:** D-pad sol/sağ yuva, yukarı/aşağı renk, A gönder, X yuvayı temizle, B geri al, Y ipucu, - yeni oyun, + duraklat /
  D-pad left/right slot, up/down colour, A submit, X clear slot, B undo, Y hint, - new game, + pause.
- **Klavye / Keyboard:** 1–8 renk, oklar, Enter gönder, Backspace geri al, Delete temizle, H ipucu, N yeni oyun, Esc duraklat /
  1–8 colour, arrows, Enter submit, Backspace undo, Delete clear, H hint, N new game, Esc pause.

Kurulum: Uygulama Mağazası > Oyunlar
