# Hafıza Kartları / Memory Cards

Kartları ikişer ikişer çevirip aynı simgeli eşleri bulun; üç tahta boyutu, süre ve hamle rekorları, ipucu ve aynı cihazda iki oyunculu mod.
Flip two cards at a time and find the matching pairs; three board sizes, time and move records, hints and a two-player mode on one console.

## Kontroller / Controls

- **Dokunmatik / Touch:** karta dokunun / tap a card.
- **Kumanda / Controller:** D-pad imleç, A çevir, Y ipucu (bir kart açıkken eşini gösterir), X yeni oyun, L/R boyut, + veya B duraklat /
  D-pad cursor, A flip, Y hint (shows the partner of the open card), X new game, L/R size, + or B pause.
- **Klavye / Keyboard:** oklar + Enter/Boşluk, H ipucu, N yeni oyun, 1–3 boyut, Esc duraklat /
  arrows + Enter/Space, H hint, N new game, 1–3 size, Esc pause.

Kurulum: Uygulama Mağazası > Oyunlar
