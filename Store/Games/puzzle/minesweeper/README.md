# Mayın Tarlası / Minesweeper

Üç zorluk seviyeli klasik mayın temizleme bulmacası

Classic mine-clearing puzzle with three difficulties

Daha önce Nexvyn OS ile birlikte geliyordu; 1.0 sürümünden itibaren isteğe bağlı olarak **Uygulama Mağazası > Oyunlar** bölümünden yüklenir. Kimliği (`minesweeper`) aynı kaldığı için eski veriler korunur.
