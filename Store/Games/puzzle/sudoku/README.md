# Sudoku / Sudoku

Her oyunda yeniden üretilen ve tek çözümü olan Sudoku bulmacaları: kolay, orta ve zor. Kalem notları, yanlışları kırmızıyla gösterme (kapatılabilir), seçili satır/sütun/kutu ve aynı rakamların vurgulanması, ipucu, geri alma, süre ve her zorluk için en iyi süre.
Freshly generated Sudoku puzzles with exactly one solution: easy, medium and hard. Pencil notes, mistakes shown in red (can be turned off), highlights for the selected row/column/box and matching digits, hints, undo, a timer and the best time for every difficulty.

## Kontroller / Controls

- **Dokunmatik / Touch:** hücreye dokunun, sonra alttaki/yandaki tuş takımından rakam seçin / tap a cell, then a digit on the number pad.
- **Kumanda / Controller:** D-pad imleç, A seçili rakamı yazar, L/R rakam değiştirir, X siler, Y not modu, B geri al, - ipucu, + duraklat /
  D-pad cursor, A writes the current digit, L/R change the digit, X erase, Y notes mode, B undo, - hint, + pause.
- **Klavye / Keyboard:** oklar, 1–9 yaz, 0/Backspace sil, N not modu, Z geri al, H ipucu, Esc duraklat /
  arrows, 1–9 write, 0/Backspace erase, N notes mode, Z undo, H hint, Esc pause.

Kurulum: Uygulama Mağazası > Oyunlar
