## Install

**Store:** App Market > Themes > Classic > Get, then Apply. **File:** open `classic-95.nxvtheme` in Files and choose Install and Apply.

Themes are managed in *System Settings > Appearance > Themes* (Undo, Restore Defaults). Everything in this pack is original: the background is a flat color, the icons are transforms of Nexvyn OS's own icon set, the sounds are synthesized and the pixel font (Pixel Operator) is CC0.

Format: Nexvyn OS `docs/NXVAPP_FORMAT.md`, section 9.
