## Install

**Store:** App Market > Themes > Crystal > Get, then Apply. **File:** open `crystal.nxvtheme` in Files and choose Install and Apply.

Themes are managed in *System Settings > Appearance > Themes* (Undo, Restore Defaults). Everything in this pack is original: the wallpaper is drawn by a script, the icons are drawn for this theme by a script and the sounds are synthesized.

## Development

    python tools/gen_style_themes.py    (in the Nexvyn OS source repository)

Format: Nexvyn OS `docs/NXVAPP_FORMAT.md`, section 9.
