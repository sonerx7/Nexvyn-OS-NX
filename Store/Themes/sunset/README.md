# Gün Batımı / Sunset

Parlayan akşam göğünün altında sıcak tonlu tepeler; açık görünüm ve turuncu vurgu rengi.
Warm layered hills under a glowing evening sky, in the light appearance with an orange accent.

## Özellikler / Features

- Açık görünüm / Light appearance
- Turuncu vurgu rengi (sistem renklerinden biri) / Orange accent color (one of the system colors)
- Parlayan güneş ve bulut şeritleri / Glowing sun and cloud streaks

## Kurulum / Install

- **Mağaza:** Uygulama Mağazası > Temalar > Gün Batımı > Al. / **Store:** App Market > Themes > Sunset > Get.
- **Dosya / File:** `sunset.nxvtheme` dosyasını Dosyalar'da açın, **Yükle ve Uygula**'ya basın. / Open
  `sunset.nxvtheme` in Files and choose **Install and Apply**.

Temalar `~/Library/Themes/com.sonerx7.theme.sunset/` içine kurulur; *Sistem Ayarları > Görünüm > Temalar*'dan değiştirilir,
kaldırılır ya da **Varsayılanlara Dön** ile eski görünüme dönülür. / Themes are installed in
`~/Library/Themes/com.sonerx7.theme.sunset/` and managed in *System Settings > Appearance > Themes* (**Restore Defaults** brings back
the standard look).

## Geliştirme / Development

Duvar kâğıtları ve önizleme Python ile üretilir (Pillow + numpy). / The wallpapers and
the preview are generated:

    python Store/Themes/tools/gen_themes.py sunset
